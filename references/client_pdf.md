# 命主版 PDF（给命主本人读的交付物）

八章报告是给命理师看的；命主版 PDF 是**命理师转发给命主本人**的成品。它不是新的分析，是对已有报告的**翻译、筛选、排版**——不加新判断、不改确定性。

**触发**：用户说"生成 PDF""命主版""给命主看的版本""做成文件发给她/他"。

**组成**：
- `templates/client_report.html`：样式 + 全部章节骨架（`{{占位符}}` + 注释说明）
- `scripts/render_pdf.py`：HTML → A4 PDF（Edge/Chrome 无头打印）+ 分页检查 + 预览图

---

## 工作流

1. **确认素材**：本会话已出八章报告；没有则先读 `命主档案/{标识}_命盘分析_*.md` 最新一份。**再读命主档案**——已收敛的分支（如"未婚有男友"）决定专题和感情部分怎么写。
2. **复制模板**：`templates/client_report.html` → `命主档案/{标识}_命盘分析_命主版.html`
3. **填内容**：按下方「章节映射」「必须删掉/改写」逐节替换占位符；可选的专题节（四）没有就删掉，后续编号顺延。
4. **渲染**：
   ```bash
   python scripts/render_pdf.py 命主档案/{标识}_命盘分析_命主版.html --preview <scratchpad>/preview
   ```
   脚本会拒绝残留 `{{占位符}}` 的文件；输出默认与 HTML 同名 `.pdf`。
5. **修分页**：看脚本输出的逐页表，有 `⚠️ 溢出尾页` 就按「分页修正」处理后重跑，直到"✓ 无溢出尾页"；再抽看 `sheet*.png` 总览图确认没有错位。
6. **收尾**：命主档案头部记一行（PDF 路径 + 依据的分支 + 日期）；把 PDF 发给用户（有 SendUserFile 就用它）。HTML 源文件留在命主档案里，命主反馈后改 HTML 重跑即可。

**目标篇幅**：12–14 页（含封面）。每章 1 页为主，"今年"可 2 页。

## 章节映射

| 命主版 | 来源（八章报告） | 写法要点 |
|---|---|---|
| 封面 | 排盘 | `{年柱}年 · 男/女命`；公历（命主给农历时括注农历）；出生地；真太阳时 · 时辰 |
| 一 你的命盘 | 排盘 + Step 1–2 | 宫位表；日主一句话定调；五行数 + "X 是你的底色"；大运表（岁数/年份/干支/一句话性质，当前运 `cur`，按脚本交运时刻判断）；时辰、岁数、交运日口径 note；夏令时或未校正经度时在 note 里写明 |
| 二 你是什么样的人 | 二、人格画像 | 5 条；h3 = 用行为说的倾向（不写性格形容词）；第一段 = 他能对号入座的具体场景；第二段 = 另一面/代价 + 一句能照做的做法；盘上依据最多半句，可省。写法见 style_guide.md「通俗层的第二个坑」 |

| 七 整体画像 | 六、整体画像 | **原文按段放入** `.narrative`，不改写 |
| 八 强能量年份 | 七、S/P 地图 | 外触 / 内驱两表（过往行 `past`）+ 这张图说明什么 + 经营窗口 |

## 必须删掉 / 改写

**删掉**
- 命理观察块、【稳】【分】【待】标注、🔥✨🔴⚠️ 等信号符号、"S复核""岁运并临"等脚本标签
- 命主档案、反馈收敛、元规则等内部机制说明（第十节只保留"为什么请你核对"的一句话理由）
- 给命理师的备注、流派分歧讨论
- **未经反馈校准、容易被读成点预测的远期窗口**（如"合型婚恋窗口在某年"）——只留在命理师版
- 已被命主反馈排除的分支（如命主未婚，就不写"已婚的话……"）

**改写**
- S 级面向未收敛 → "如果这股力量落在 X 上……"，列几个方向，不下单一结论
- 感情、今年运势按档案已收敛的状态写（已婚 / 未婚有伴侣 / 单身）
- 仍守 SKILL.md「严格禁止」与 style_guide.md 全部措辞红线；第七章散文里不出现公历年份；未来年份一律是"经营窗口"不是"要小心的年份"
- 岁数统一"年份 − 出生年"，并在第一章 note 里说明口径（年底生日要补一句"实际周岁少一岁"）

**术语 → 白话对照（命主版正文里不出现左列词）**

| 术语 | 命主版写法 |
|---|---|
| 官杀 / 七杀（压力面） | 来自外部的要求、压力和责任 |
| 正官（女命） | 代表伴侣、也代表工作单位的那颗星 |
| 财星（男命妻星） | 代表钱、也代表伴侣的那颗星 |
| 印 | 学习、资格、专业，以及愿意带你的人 |
| 食伤 | 负责表达、输出的那部分力量 |
| 比劫 | 同辈这股力量 |
| 偏财 | 额外财运 / 父亲一方 |
| 日支 | 婚姻那一格 |
| 月令 / 月支 | 代表工作环境（和父母）的那一格 |
| 时柱 | 子女、晚年那一格 |
| 禄 | 你自身能量的位置 |
| 冲 / 合 / 害（穿）/ 伏吟 | 被冲动 / 合在一起、被合住 / 被暗暗穿了一下 / 被再次触动 |
| 坐实（有根）/ 虚透 | 实的、有根的 / 浮的、没根的 |
| 身弱 / 身旺 | 自身能量偏弱（但有依靠）/ 自身能量足 |

## 版式组件速查（模板 CSS 已定义，不要改样式区）

| 类 / 元素 | 用途 |
|---|---|
| `section` | 每章默认另起一页；紧跟封面的第一章用 `section.cont` |
| `h2 > .num` | 章节号（一、二…） |
| `.lead` | 章首导语（金棕色） |
| `table.big` | 四柱大字表 |
| `.wuxing` / `.zero` | 五行格；数量为 0 的数字加 `zero` 变灰 |
| `tr.cur` / `tr.past` | 当前行高亮 / 已过去的行变灰 |
| `.note` | 说明框（时辰口径、节气月说明、"不是危险年份"） |
| `.tag` | 一字标签（钱 / 事 / 身 / 言 / 情 / 比） |
| `.narrative` | 第七章散文，首行缩进 |
| `.newpage` | 给 h3 加上，整块内容另起一页 |
| `.small` | 表格里的小字副行 |
| `.end` | 文末"这份分析怎么用" |

## 分页修正

表格设置了 `page-break-inside: avoid`：一张表放不下时会**整张被推到下一页**，上一页留白、下一页只剩一张表——这是溢出尾页最常见的来源。按顺序试：

1. **整块另起一页**：给该小节的 h3 加 `class="newpage"`（适合一章里有两个独立专题）
2. **合并表格行**：如节奏表里已过去的几个月合成一行"回看"
3. **精简文字**：合并意思相近的引言段落、缩短小结；每次少 3–4 行通常就够
4. **去掉表格小字副行**：如核对表里"约 X 岁"的第二行

不要为了塞进一页而改字号、改页边距——各章版式要和其他命主的 PDF 保持一致。
